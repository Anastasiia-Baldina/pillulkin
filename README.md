# Умная аптечка Пилюлькин

Умная аптечка «Пилюлькин» предназначена для упрощения учёта домашней аптечки, контроля сроков годности лекарств, хранения симптомов пациента и предоставления врачу временного доступа к этой информации. Приложение позволяет определять возможный диагноз по симптомам при помощи модели машинного обучения, искать лекарства по названию или симптомам, а также получать назначения от врача и переносить их в аптечку.

## Сборка и запуск

### Требования

- **JDK 21** — для сборки backend
- **Android Studio Ladybug** или новее — для сборки Android-приложения
- **Android SDK 36** (minSdk 24)
- **Docker** и **Docker Compose** — для запуска backend, базы данных и сервиса машинного обучения

### Клонирование репозитория

```bash
git clone https://github.com/Anastasiia-Baldina/Pillulkin.git
cd Pillulkin
```

### Запуск серверной части

Серверная часть включает PostgreSQL, Spring Boot backend и сервис машинного обучения. Все сервисы запускаются через Docker Compose:

```bash
docker compose up -d
```

После запуска доступны:
- Backend API: `http://localhost:8080`
- ML-сервис: `http://localhost:8001`
- PostgreSQL: `localhost:5432`

Миграции базы данных (Flyway) применяются автоматически при старте backend.

### Сборка и запуск Android-приложения

1. Откройте папку `Pillulkin` в Android Studio
2. Подождите завершения синхронизации Gradle
3. Для сборки APK выполните:

```bash
./gradlew assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`

4. Запустите приложение на эмуляторе или подключённом устройстве через Android Studio

### Подключение к серверу

По умолчанию приложение обращается к `http://10.0.2.2:8080` (адрес хоста для Android-эмулятора). Для запуска на физическом устройстве замените `10.0.2.2` на IP-адрес компьютера в локальной сети в файле `NetworkModule.java`.

## Основной функционал

### Для пациента

- **Ведение аптечки** — добавление, редактирование и удаление лекарств с указанием срока годности и количества. Лекарства с истекающим сроком и просроченные помечаются автоматически
- **Поиск лекарств** — поиск по названию или по симптомам. Поиск по названию ищет в справочнике препаратов, поиск по симптомам подбирает лекарства, которые могут помочь
- **Добавление своего препарата** — если лекарства нет в справочнике, пациент может добавить его вручную, указав название, дозировку, форму выпуска, действующее вещество, срок годности и количество
- **Симптомы** — ведение списка симптомов с датами. Симптомы старше 7 дней помечаются как устаревшие, их можно обновить
- **Диагностика** — определение возможного диагноза на основе выбранных симптомов при помощи модели машинного обучения. Модель может задать уточняющие вопросы для повышения точности
- **Напоминания** — создание напоминаний о приёме лекарств с указанием времени. Напоминания отправляются в виде уведомлений и сохраняются после перезагрузки устройства
- **Профиль** — хранение имени, возраста, аллергий, противопоказаний и заметок. Эта информация доступна врачу при просмотре аптечки
- **Код доступа для врача** — генерация одноразового кода, который врач использует для просмотра аптечки пациента. Код действителен 1 час
- **Рецепты врача** — просмотр назначений от врача. Рецепт можно перенести в аптечку одним нажатием
- **Оффлайн-режим** — без входа через Google данные хранятся локально на устройстве. При последующей авторизации данные синхронизируются с сервером

### Для врача

- **Вход по коду** — врач вводит одноразовый код, полученный от пациента, и получает временный доступ к аптечке
- **Просмотр аптечки пациента** — список лекарств с информацией о каждом препарате, а также профиль пациента: возраст, аллергии, противопоказания
- **Поиск лекарств** — поиск по названию или активному веществу для добавления в аптечку пациента, либо поиск по симптомам для подбора препаратов
- **Добавление своего препарата** — врач может добавить лекарство, которого нет в справочнике, в аптечку пациента
- **Диагностика** — врач может запустить определение диагноза по симптомам пациента с уточняющими вопросами от модели машинного обучения
- **Назначение рецептов** — врач назначает препарат с указанием частоты приёма, связи с приёмами пищи, смещения по времени и дополнительных инструкций
